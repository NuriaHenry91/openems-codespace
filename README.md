# ⚡ OpenEMS in GitHub Codespaces

## 访问地址
| 服务 | 端口 | 访问方式 |
|------|------|----------|
| **Web UI** | 8080 | Ports → 8080 → 🌐 |
| **Edge UI** | 8082 | Ports → 8082 → 🌐 |

## 默认账号
- **用户名**: `admin`
- **密码**: `admin`

## 功能说明
- 支持 **Modbus TCP/RTU** 设备接入
- 内置 **光伏、储能、负载** 控制逻辑
- 可扩展 **DL/T645、IEC104** 驱动（需 Java 开发）

> 💡 提示：首次启动需等待 1-2 分钟初始化数据库
